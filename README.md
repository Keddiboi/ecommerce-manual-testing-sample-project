# E-Commerce Website – Manual Testing

## About the Project
A beginner-friendly Manual Testing portfolio project for an e-commerce web application.

## Objective
To practice writing test cases, executing functional tests, and documenting defects.

## Modules Tested
- Login
- Products
- Product Sorting
- Cart
- Checkout
- Order Placement
- Navigation
- Logout

## Testing Performed
- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
- Smoke Testing
- Basic Regression Testing

## Project Files
| File | Description |
|---|---|
| `Test_Cases.xlsx` | Manual test scenarios and detailed test cases |
| `Bug_Report.xlsx` | Sample defect reports |
| `Test_Summary_Report.docx` | Test execution summary and conclusion |
| `README.md` | Project documentation |
